# Restaurant Website — Demo by Dinal Studios

**A complete, elegant restaurant website demo: hero, chef specials, full menu organized by category, table reservation form, location details and opening hours — in one self-contained HTML file.**

No frameworks, no build step, no external assets. Open `index.html` in any browser and it works on phone, tablet and desktop.

## Features

- Sticky responsive header with mobile hamburger menu
- Full-screen hero with reservation call-to-action
- **Chef specials** section with signature dishes and prices
- **Full menu by category** — Starters, Main Courses, From the Grill, Desserts & Drinks — with tab switching, dotted price leaders and spicy markers, all rendered from a clean JavaScript data object (easy to edit dishes and prices)
- **Table reservation form** — name, phone, date (past dates blocked), time slots, guest count, seating area and special requests, with a friendly confirmation message
- **Location & hours panel** — address, phone, parking notes and an opening-hours table that highlights the current day automatically
- "Order a website like this" call-to-action linked to the Dinal Studios LaborX profile
- Fully responsive, mobile-first, classic restaurant typography (serif headings)

## Tech Used

- HTML5 (semantic sections)
- CSS3 (custom properties, grid, flexbox, gradients, SVG icons, responsive media queries)
- Vanilla JavaScript (menu rendering, tab filtering, form handling, day highlighting)
